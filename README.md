# Symbolic Derivative Calculator

Консольный калькулятор математических выражений на C++17. Строит абстрактное синтаксическое дерево (AST), вычисляет выражение и находит его производную по заданной переменной.

## Возможности
- **Лексер:** разбивает выражение на токены и находит лексические ошибки (ведущие нули, `1.`, число, слитное с буквой, неизвестный символ).
- **Парсер:** рекурсивный спуск с учётом приоритетов, правой ассоциативности `^` и унарных `+`/`-`.
- **Вычисление** выражения с переменными.
- **Символьное дифференцирование:** правила для суммы, разности, произведения, частного, степени (в том числе с переменным показателем) и сложной функции.
- **Функции:** `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `exp`, `log`, `sqrt`.
- Обработка ошибок области определения (например, `sqrt` от отрицательного числа) и деления на ноль (`inf`).

## Архитектура
Узлы AST наследуются от абстрактного класса `Expression` и реализуют `evaluate`, `derivative`, `toString` и `clone`. Владение узлами организовано через `std::unique_ptr`.

`Number` · `Variable` · `UnaryOp` · `BinaryOp` · `Function`

## Сборка и запуск
```bash
g++ -std=c++17 -O2 main.cpp -o calculator
./calculator < examples/input.txt
```

## Формат ввода
Первая строка — режим: `evaluate`, `derivative` или `evaluate_derivative`. Далее:
```
<число переменных>
<имена через пробел>
<значения через пробел>
<выражение>
```
Если первая строка не является командой, программа работает в режиме лексера и печатает токены по одному на строку.

## Примеры
**Вычисление**
```
evaluate
2
x y
3 4
x^2 + y
```
Вывод: `13`

**Значение производной по `x` в точке**
```
evaluate_derivative
1
x
3
x^2
```
Вывод: `6`

**Режим лексера**
```
3.5+x*(2)
```
Вывод: токены `3.5`, `+`, `x`, `*`, `(`, `2`, `)`, каждый на своей строке.
